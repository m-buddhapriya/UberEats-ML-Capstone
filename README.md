# Uber Eats Operational & Customer Intelligence System

## Project Objective

This project aims to build an end-to-end analytics and machine learning system for Uber Eats operational and customer intelligence.

The project will analyze customer behavior, restaurant performance, delivery operations, customer reviews, and payment behavior.

Machine learning and analytics will be used to generate actionable business insights.

---

## Datasets

The project contains seven synthetic datasets:

1. Customers
2. Restaurants
3. Drivers
4. Orders
5. Deliveries
6. Reviews
7. Payments
